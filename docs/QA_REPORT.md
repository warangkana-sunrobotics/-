## ปัญหาที่พบ

### #1 หน้าวิธีเล่นมี scroll แนวนอนบนมือถือ
- **ความรุนแรง:** กลาง · **เจ้าของ:** main (`src/screens/HowToPlay.tsx` / `howto.css`)
- **วิธีทำซ้ำ:** เปิดจอกว้าง 390×844 แล้วกด "วิธีเล่น" จะได้ `scrollWidth` 532 ขณะที่ `clientWidth` 390 ทั้งหน้าเลื่อนออกด้านข้าง และทุก panel กว้าง 516px
- **สาเหตุ:** `.howto` ใช้ `display:grid` grid item มี `min-width:auto` อยู่แล้ว ทำให้คอลัมน์ขยายตาม `.howto-table { min-width: 480px }` จึงไม่ได้ใช้ `overflow-x:auto` ของ `.howto-table-wrap`
- **แนวทางแก้:** ใส่ `.howto { grid-template-columns: minmax(0, 1fr); }` หรือ `.howto > * { min-width: 0; }`

### #2 หน้าจบเกม (ตารางคะแนน) มี scroll แนวนอนบนมือถือ
- **ความรุนแรง:** กลาง · **เจ้าของ:** gameplay-ui (`src/screens/game/game.css`)
- **วิธีทำซ้ำ:** เปิดจอกว้าง 390×844 แล้วเล่นจนจบเกม หรือโหลดเซฟที่อยู่ในสถานะ gameOver แล้วกด "เล่นต่อ" จะได้ `scrollWidth` 806 ทั้งหน้ากว้างตามตาราง (`phone-gameOver.png`)
- **สาเหตุ:** เหมือน #1 ตรงที่ `.winner { display:grid }` ขยายตาม `.score-table { min-width: 760px }` ทำให้ `.table-wrap { overflow-x:auto }` ไม่มีผล
- **แนวทางแก้:** ใส่ `.winner { grid-template-columns: minmax(0, 1fr); }` หรือ `.winner > * { min-width: 0; }`

### #3 การ์ดตัวละคร 9 จาก 10 ใบยังเป็นการ์ดตัวแทน
- **ความรุนแรง:** ต่ำ (ข้อมูลเพื่อทราบ) · **เจ้าของ:** map-and-assets
- **รายละเอียด:** ตอนนี้มีแค่ `public/assets/cards/yai-on.webp` ใบอื่นใช้การ์ดตัวแทนที่มีข้อความ "ภาพการ์ดยังไม่มา" ซึ่งทำงานถูกต้อง แต่ผู้เล่นเห็นข้อความนี้ในหน้าตั้งค่าผู้เล่น หน้าส่งเครื่อง และหน้าจบเกม ภาพที่ขาดยังทำให้เกิด 404 ใน console ทุกครั้งที่แสดงการ์ด

### #4 รีโหลดหน้าแล้วกลับไปหน้าแรก ไม่กลับเข้าเกมทันที
- **ความรุนแรง:** ต่ำ · **เจ้าของ:** main (`src/App.tsx`)
- **วิธีทำซ้ำ:** อยู่ในเกม phase ใดก็ได้ แล้วกด F5 จะกลับมาหน้าแรก และต้องกด "เล่นต่อ" (`home-resume`) ก่อน จึงจะกลับไปที่ handoff / reveal / summary เดิม
- **ผลต่อเกม:** สถานะเกมยังครบ ไม่มีการคิดผลซ้ำ แค่เพิ่มขั้นตอนอีกหนึ่งคลิก ถ้าต้องการให้รีโหลดแล้วกลับเข้าเกมเลย ให้เปลี่ยนค่าเริ่มต้นของ `screen` เป็น `'game'` เมื่อ `loadGame()` คืนค่าไม่ใช่ null

### #5 ข้อมูลเล็กน้อย
- **ข้อความเหตุผลไม่ตรงกับวิธีเล่น** (ต่ำ · main): หน้าวิธีเล่นเขียนว่าจะเห็นข้อความ "กะเต็มแล้ว" แต่ข้อความจริงคือ "กะที่จุดนี้เต็มแล้วในช่วงนี้ (มีคนได้สิทธิ์ก่อน)" ความหมายตรงกัน
- **ฟอนต์พึ่ง Google Fonts** (ต่ำ · main): ฟอนต์โหลดจาก fonts.googleapis.com ถ้าออฟไลน์ เบราว์เซอร์จะใช้ฟอนต์ไทยของระบบแทน ซึ่งยังอ่านได้แต่หน้าตาจะเปลี่ยนไป
- **phase ในเซฟระหว่างวางแผน:** ระหว่างวางแผน localStorage เก็บ phase เป็น `planning` จริง แล้ว `normalizeLoaded` แปลงเป็น `handoff` ตอนโหลด ซึ่งทำงานถูกต้อง เครื่องมือภายนอกที่อ่านเซฟตรงควรรู้ไว้
