# สิ้นเดือนยังไหว

บอร์ดเกมวางแผนชีวิตในเมืองไทย สำหรับผู้เล่น 2–8 คน เล่น 8 สัปดาห์ในเกม
เว็บเกมภาษาไทย เล่นบนเบราว์เซอร์เครื่องเดียวแบบผลัดกันใช้หน้าจอ (hot-seat)
สร้างด้วย React + TypeScript + Vite และบันทึกเกมไว้ใน localStorage ของเบราว์เซอร์

## เปิดเกม

```bash
npm install
```

```bash
npm run dev
```

เปิด http://localhost:5173

ถ้าต้องการรันจากไฟล์ build

```bash
npm run build
```

```bash
npm run preview
```

แล้วเปิด http://localhost:4173

## ทดสอบ

| คำสั่ง | ตรวจอะไร |
|---|---|
| `npm test` | Vitest: กติกาเกม (`src/game`), ข้อมูลแผนที่และภาพ (`src/data`), ตรรกะหน้าตั้งเกม (`src/screens/setup`) |
| `npm run typecheck` | TypeScript |
| `npm run build` | type check + build สำหรับ production |
| `npm run test:e2e` | Playwright เล่นเกมจริงในเบราว์เซอร์ (build และเปิด preview ให้เอง) ภาพหน้าจออยู่ที่ `tests/e2e/out/` |

## เพิ่มหรือเปลี่ยนภาพ

ไฟล์ต้นฉบับที่ได้รับเก็บไว้ที่ `assets/incoming/` เกมใช้สำเนาชื่อสั้นใน `public/assets/`
ดูตารางจับคู่ไฟล์ทั้งหมดที่ `docs/ASSETS.md`

**การ์ดตัวละคร**
1. วางไฟล์ที่ `public/assets/cards/<id>.webp` โดย id คือ
   `manao`, `pa-nid`, `ton`, `fang`, `lung-chai`, `kaew`, `mek`, `yai-on`, `pete`, `nam`
2. เพิ่ม id นั้นใน `AVAILABLE_CARDS` ของ `src/data/assets.ts`

การ์ดที่ยังไม่มีภาพจะแสดงเป็นการ์ดตัวแทน (สีประจำตัวและชื่อย่อ) ชื่อ อาชีพ และคำอธิบายเป็นข้อความจริงเสมอ

**แผนที่**
1. แทนไฟล์ `public/assets/maps/<canal|market|hill|park>.webp` ด้วยภาพขนาดเดิม
2. ถ้าตำแหน่งวงกลมหรือถนนในภาพเปลี่ยน ให้แก้ `scripts/map_specs.py`
3. รัน `python3 scripts/build_maps.py` เพื่อสร้าง `src/data/maps/*.ts` ใหม่ สคริปต์จะตรึงจุดเข้ากับวงกลมที่ตรวจพบและวาดภาพซ้อนไว้ตรวจ
4. รัน `npm test` เพื่อตรวจว่ากราฟเชื่อมกันครบ

## การตีความกติกาในรุ่นแรก

ไม่มีไฟล์กติกาต้นแบบแยกมาให้ จึงใช้กติกาจากพรอมต์ตามที่สรุปไว้ใน `docs/RULES.md` ทั้งหมด
จุดที่พรอมต์ไม่ได้ระบุไว้ ตัดสินใจดังนี้

- **พัก:** พักได้ที่บ้านทุกหลังและทุกสวน ไม่จำกัดเฉพาะบ้านของตัวเอง
- **เรียนซ้ำ:** ผู้ที่มีทักษะแล้วเรียนซ้ำไม่ได้ (เหตุผล "มีทักษะแล้ว")
- **ลำดับตรวจเงื่อนไขกิจกรรม:** สถานที่ → ทักษะ → เวลา → เงิน → พลัง → ที่ว่างของกะหรือทำเล
- **ร้านกับข้าวกล่องในช่วงเดียวกัน:** ถ้าผู้ที่สิทธิ์มาก่อนเปิดร้านในช่วงนั้น ผู้ที่สิทธิ์มาทีหลังซื้อข้าวกล่องจากร้านนั้นได้ทันทีในช่วงเดียวกัน
- **ลำดับวางแผน:** ผู้เล่นวางแผนตามลำดับสิทธิ์ของสัปดาห์นั้น
- **ภาพแผนที่:** จุดที่ถนนแยกแต่ในภาพไม่มีวงกลม ได้เพิ่มเป็นจุดทางแยกซึ่งกดเดินผ่านได้
